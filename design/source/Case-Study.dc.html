02

Problem

Research material lives in many formats (PDFs, DOCX files, spreadsheets and datasets) while the report is written somewhere else. When an AI assistant answers without pointing back to that material, its claims cannot be checked. ResearchHub starts from the opposite premise: every generated claim should stay traceable to the source it came from.

03

Product and users

For: students and researchers working in teams. What the workspace lets them do:

  • Work with PDFs, DOCX files, spreadsheets and datasets
  • Write shared reports together, in realtime
  • Ask source-grounded AI questions
  • Generate cited content
  • Run reproducible data analyses with provenance back to the source

06

Key engineering challenges

  1. Keeping claims traceable

    Generated text must stay linked to the exact source chunks it relies on, across versioned sources.

  2. Isolated scientific computation

    Reproducible analyses run in an isolated Python environment, apart from the web application.

  3. Realtime collaborative editing

    Shared documents built on Yjs, Hocuspocus and Tiptap / ProseMirror.

  4. Authorization and workspace boundaries

    Access to sources, documents and AI features is scoped by workspace.
