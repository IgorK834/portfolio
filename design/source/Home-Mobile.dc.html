ResearchHub

Source-grounded collaborative AI workspace for students and researchers.

Overview

A collaborative research environment where teams work with PDFs, DOCX files, spreadsheets and datasets, write shared reports, ask source-grounded AI questions, generate cited content and run reproducible data analyses, with provenance kept back to the source material.

Active development

Highlights

  1. Source-grounded AI / RAG

    Not a generic chatbot: citations and provenance run from each generated claim back to its source chunks.

  2. Versioned sources, audited AI calls

    Research sources are versioned. Model calls go through a structured gateway and are audited.

  3. Spring backend + Python worker

    Responsibilities are explicitly split between the Spring Boot backend and an internal FastAPI AI / data worker, with an isolated Python environment for scientific computation.

  4. Realtime editing, enforced boundaries

    Collaborative document editing, workspace authorization boundaries, and automated tests with coverage gates.

System Analizy Uwarunkowań Działki

Spatial / Investment Parcel Analysis Platform

Overview

A web application that automatically analyses the investment and planning context of a land parcel, using GIS and Polish spatial-planning datasets.

Analysis areas

  • Local spatial plans (MPZP)
  • General plans (POG)
  • OUZ and related planning data
  • Flood-risk data
  • Protected areas
  • Terrain / elevation
  • Infrastructure context
  • Map layers

Source
Private repository

Highlights

  1. Vector tiles straight from PostGIS

    Mapbox Vector Tiles generated from PostGIS; WMS previews are proxied with tile caching; coordinate transformations handled explicitly.

  2. Provenance and data quality

    Explicit provenance, quality and freshness states, and a clear difference between missing data and a confirmed absence of a restriction.

  3. Deterministic, reproducible reports

    PDF reports built from immutable analysis snapshots, plus audit ZIP exports with hashes.

  4. MPZP extraction research

    Experimental R&D

    Exploring deterministic plus LLM-assisted extraction from MPZP documents. A research track, not a finished feature of the platform.
